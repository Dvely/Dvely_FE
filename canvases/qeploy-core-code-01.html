AI Workspace에서 자연어 요청을 보내고 승인 결과를 화면에 반영하는 훅. 실제 구현은 AgentConversationPanel.tsx의 React Query mutation 흐름을 발췌·보강한 것이다.

AI Workspace는 Qeploy에서 사용자가 자연어 한 줄로 코드·배포·도메인·인프라 작업을 맡기는 핵심 화면이다. 요청은 projectId와 함께 Agent API로 보내지고, 응답의 summary·previewUrl·approval 상태가 채팅과 미리보기 패널에 바로 저장된다. 승인이 끝나면 실행 목록과 프로젝트 상태를 다시 조회한다. API가 실패하면 Toast/ErrorBoundary로 원인을 보여 준다.

다음 코드는 요청 전송과 승인 처리의 핵심이며, 코드 아래는 서버가 agent_runs에 쌓아 두는 실행 기록의 예이다. 프론트는 이 JSON을 받아 previewUrl·approval·summary를 화면에 넣고, 승인이 끝나면 같은 트리를 다시 조회한다. (관련 요구사항 QEP-REQ-03/04/05/09)
