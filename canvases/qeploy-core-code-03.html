• AgentOrchestrator.java

Decision Agent가 분류한 의도를 라우팅하고, 승인 가드레일을 통과한 뒤에만 실행하는 오케스트레이터. 중간보고 기준 구현 흐름을 발췌·단순화한 것이다.

자연어 요청이 들어오면 프로젝트를 조회하고 Decision Agent가 intent를 나눈다. requiresApproval이면 실행 전에 approvalService를 호출하고 AgentRun을 WAITING_APPROVAL로 둔다. 승인이 필요 없으면 바로 실행한다. AgentRun 상태와 AuditLog action은 한 트랜잭션에서 함께 기록한다. 정보가 부족하면 추가 질문을 남기고, 실패하면 error_type을 저장한다.

다음 코드는 저장소 조회, AgentRun 상태 전환, 승인 요청, AuditLog 기록이 한 흐름으로 보이도록 보강한 것이다. 코드 옆 트리는 agent_runs와 approvals, audit_logs에 쌓이는 기록의 예이다. (관련 요구사항 QEP-REQ-03/04/05/09)
