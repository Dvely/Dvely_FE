• DeploymentService.java

GitHub Actions로 배포를 걸고 이력을 남기는 서비스. 실제 구현 흐름을 발췌·보완한 것이다.

배포 전에 Project owner와 GitHub 권한, 배포 브랜치 정책을 확인한다. dispatch payload에 version·environment를 넣고 GitHub Actions를 실행한 뒤, QUEUED 상태로 이력을 저장한다. workflow_run_id와 log_url로 로그를 연결하고, 사용자 승인 및 배포 요청을 AuditLog action으로 남긴다. 이후 상태는 QUEUED / RUNNING / SUCCESS / FAILED로 추적한다.

다음 코드는 권한 검증, dispatch payload, 상태 저장, 감사 로그 기록을 포함해 실제 구현 코드 느낌을 강화한 것이다. 코드 옆 트리는 deployment_histories와 audit_logs에 쌓이는 기록의 예이다. (관련 요구사항 QEP-REQ-03/04/05/09)
