개요 코드 변경은 preview 브랜치에 커밋하며, 배포 요청이 있을 때만 PR·merge와 버전 번호 증가가 일어난다. 개발·배포·도메인·인프라 작업은 Chat Settings 승인 On일 때 승인창을 띄운다. 승인 후에도 즉시 main에 반영하지 않는다.
기능 흐름도
<버전 관리 · 승인 연계도 (A05, A06)>
1 배포 요청 시에만 PR을 만들고 main/production에 merge하며 버전(v1, v2…)을 올린다. merge 이력을 기준으로 특정 버전 배포·롤백이 가능하다.
2 Chat Settings에서 승인 On/Off를 관리한다. On이면 한 줄 요약 승인창을 띄우고, 거절 시 종료한다. Off이면 승인창을 생략할 수 있다. 승인 후에도 즉시 main/production에는 반영하지 않는다.
