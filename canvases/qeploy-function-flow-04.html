개요 정적 프론트엔드는 GitHub Pages, 그 외는 개인 AWS/GCP 연결 후 배포한다. 도메인은 기본 URL, 사용자 지정 qeploy.com 서브도메인, 커스텀 도메인을 지원한다. 인프라 비용·리소스·환경변수 변경은 승인 대상이다.
기능 흐름도
<배포 · 도메인 · 인프라 연계도 (A07~A10)>
1 배포 요청 시 Pages 또는 연결된 클라우드로 반영한다. 미연결이면 클라우드 설정을 비활성한다. 실패 시 쉬운 설명·로그 일부·수정안 1개를 보여주고 승인 후 재시도한다.
2 기본 배포 URL, 사용자 지정 서브도메인, 커스텀 도메인(DNS/HTTPS)을 연결한다. 인프라 운영·환경변수(Secrets 숨김)는 자연어로 요청하며, Overview에서 상태·버전·최근 이력을 확인한다.
