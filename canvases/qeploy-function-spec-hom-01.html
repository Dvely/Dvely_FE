기능 번호 HOM-01-01
기능 명 홈 (작업 시작)
기능설명

로그인 후 첫 화면.

자연어로 작업을 입력하고, 프로젝트를 선택한 뒤 AI Workspace로 이동한다.

하단에서 템플릿을 탐색·첨부해 작업을 시작할 수 있다.
처리내용

■ 자연어 작업 요청

입력창에 작업을 입력하고 전송(↑) 또는 Enter를 누르면, 선택한 프로젝트의 AI Workspace로 이동한다.

placeholder: “작업을 할당하거나 무엇이든 질문하세요”

프로젝트가 없으면 “먼저 프로젝트를 생성해 주세요.”를 표시하고 이동하지 않는다.

빠른 작업(슬라이드 제작, 웹사이트 구축, 데스크톱 앱 개발, 디자인)을 누르면 입력창에 초안이 채워진다.

■ 프로젝트 선택

‘프로젝트 선택’을 누르면 프로젝트 목록이 열린다.

선택하지 않으면 최근 수정한 프로젝트를 사용한다.

■ 템플릿 탐색

‘탐색’ / ‘내 템플릿’ 탭으로 전환한다.

스타일 · 테마 · 정렬(인기순/최신순)로 목록을 걸러 본다.

템플릿 카드를 누르면 프롬프트에 템플릿이 첨부된다. 미리보기는 프로젝트 생성으로 이어진다.

‘내 템플릿 추가’로 사용자 템플릿을 추가한다.
비고

■ 연결되는 기능

: AI Workspace (자연어 요청)

: 프로젝트 목록

: 템플릿 · 프로젝트 생성

: 알림 · 프로필 설정
