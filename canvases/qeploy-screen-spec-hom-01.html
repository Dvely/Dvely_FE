Devely 1.0 Lite · 로그인 후 첫 화면

기능 정의
기능 번호 HOM-01-01
기능 명 홈 (작업 시작)
기능설명 로그인 후 첫 화면. 자연어로 작업을 입력하고 프로젝트를 고른 뒤 AI Workspace로 이동한다. 하단 템플릿으로도 시작할 수 있다.
처리내용
1

자연어 작업 요청
전송 또는 Enter → 선택 프로젝트의 AI Workspace로 이동. 프로젝트가 없으면 “먼저 프로젝트를 생성해 주세요.” 빠른 작업 칩은 입력창에 초안을 채운다.

2

프로젝트 선택
목록에서 고른다. 고르지 않으면 최근 수정 프로젝트를 쓴다.

3

빠른 작업
슬라이드 · 웹사이트 · 데스크톱 앱 · 디자인.

4

템플릿 탐색
탐색 / 내 템플릿. 스타일·테마·정렬. 카드 선택 시 프롬프트에 첨부, 미리보기는 프로젝트 생성.
비고

: AI Workspace (자연어 요청)

: 프로젝트 목록

: 템플릿 · 프로젝트 생성

: 알림 · 프로필 설정
