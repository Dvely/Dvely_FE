기능 명
프로젝트 목록
기능설명
생성한 프로젝트를 카드로 보고 생성·필터·정렬한다. 카드를 누르면 해당 프로젝트로 이동한다.
처리내용
1

프로젝트 생성
‘+ 프로젝트 생성’을 누르면 이름 입력 창이 열린다. 빈 프로젝트로 추가된다.

2

보기 전환
그리드 / 목록으로 표시한다.

3

필터 · 정렬
전체 / 배포 전 / 배포 중 / 배포 완료. 최근 수정순 / 이름순.

4

프로젝트 카드
상태·템플릿, 이름, URL 또는 “홈에서 템플릿을 골라 주세요.” 클릭 시 프로젝트로 이동.
