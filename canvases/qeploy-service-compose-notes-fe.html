1. front-end

  1. ① 사용자가 브라우저에서 qeploy.com에 접속하면 요청은 Cloudflare(HTTPS)를 거쳐 Nginx로 전달된다.
  2. ② Nginx는 정적 파일을 React dist로 제공하고, Projects · Overview · AI Workspace 화면을 렌더링한다.
  3. ③ 사용자는 자연어로 생성·수정·배포를 요청하고, Docker Preview와 한 줄 승인 요약을 확인한 뒤 승인 / 거절한다.
  4. ④ 승인 후에도 즉시 main에 반영하지 않으며, 기본 URL · qeploy.com 서브도메인 · 커스텀 도메인을 화면에 표시한다.
