1. front-end

  1. ① 사용자가 브라우저에서 qeploy.com에 접속하면 요청은 Cloudflare(HTTPS)를 거쳐 Nginx로 전달된다.
  2. ② Nginx는 정적 파일을 React dist로 제공하고, Projects · Overview · AI Workspace 화면을 렌더링한다.
  3. ③ 사용자는 자연어로 생성·수정·배포를 요청하고, Docker Preview와 한 줄 승인 요약을 확인한 뒤 승인 / 거절한다.
  4. ④ 승인 후에도 즉시 main에 반영하지 않으며, 기본 URL · qeploy.com 서브도메인 · 커스텀 도메인을 화면에 표시한다.

2. back-end

  1. ① Nginx /api 요청을 Spring Boot Use Case · Orchestration이 처리한다. Agent 분기는 사용자에게 보이지 않는다.
  2. ② 자연어 요청을 코드 / 배포 / 도메인 / 인프라 Agent로 라우팅하고, 코드 생성·수정은 LLM이 수행한다.
  3. ③ 코드는 preview 브랜치에 커밋되고 Docker 컨테이너에서 실제 동작을 검증한다.
  4. ④ Project · AgentRun · Deployment 상태를 MySQL에 저장하고, GitHub API로 커밋 · PR · Pages를 연동한다.
