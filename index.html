Qeploy — 대화형 AI 웹서비스 빌드·배포 자동화 플랫폼

Qeploy는 만들고 싶은 웹서비스를 말로 설명하면 AI 에이전트가 코드를 만들고 고치고, 그 결과를 미리보기로 확인한 뒤 배포와 도메인 연결까지 이어 주는 웹 기반 AI 워크스페이스입니다. 배포 지식이 부족한 비개발자와 입문 개발자도 공개 가능한 URL까지 도달하게 하는 것이 목표입니다.

주요 기능

  • 의사결정 에이전트 — 자연어 명령을 코드 생성·수정, 빌드·배포, 도메인 연결, 클라우드 작업으로 분류해 실행 계획을 세우고, 요청이 모호하면 먼저 되묻습니다.
  • AI 코딩 에이전트 — 연결된 저장소의 코드를 직접 수정합니다. AI 호출에는 사용자 본인의 공식 API 키(BYOK)만 쓰며, 키는 암호화해 저장합니다.
  • Docker 프리뷰 — 변경 결과를 세션별로 네트워크가 격리된 Docker 컨테이너에서 실행해 브라우저에서 바로 확인합니다.
  • 변경 승인 — 사용자가 승인한 변경만 저장소에 반영하고 배포합니다.
  • 배포 자동화 — 프론트엔드는 GitHub Pages로, 백엔드와 데이터베이스는 사용자 본인의 AWS 계정(EC2, BYOC)으로 배포합니다.
  • 도메인 연결 — qeploy.com 서브도메인 또는 보유한 커스텀 도메인을 HTTPS로 연결합니다.

이용 흐름

  1. 프로젝트 시작 — 새로 만들기, 템플릿으로 시작하기, GitHub 저장소 불러오기
  2. AI 에이전트에 자연어로 요청
  3. 코드 수정과 빌드
  4. 프리뷰에서 실제 동작 확인
  5. 변경 승인 후 반영
  6. 배포 실행과 배포 URL 확인
  7. 필요하면 도메인 연결

요금

Free 플랜(월 0원)으로 프로젝트 1개, 에이전트 대화·미리보기, 관리형 서브도메인 배포를 쓸 수 있습니다. 팀용 Pro 플랜과 자체 클라우드용 Enterprise 플랜은 출시 예정입니다.

자주 묻는 질문

Qeploy는 어떤 서비스인가요?

자연어 대화로 웹서비스를 만들고, 미리보기로 확인하고, 배포와 도메인 연결까지 한 곳에서 처리하는 AI 웹서비스 빌드·배포 자동화 플랫폼입니다.

개발이나 배포 지식이 없어도 쓸 수 있나요?

네. 원하는 변경을 말로 요청하면 에이전트가 코드 수정, 빌드·배포, 도메인 연결, 클라우드 작업 중 무엇이 필요한지 판단해 진행합니다. 반영과 배포는 사용자가 승인한 뒤에만 일어납니다.

AI 사용 비용은 어떻게 되나요?

Qeploy는 사용자 본인의 공식 AI API 키(BYOK)로만 AI를 호출합니다. AI 사용료는 각 AI 제공사의 요금 정책에 따라 사용자 본인 계정에 청구됩니다.

배포한 서비스는 어디에서 실행되나요?

프론트엔드는 연결한 GitHub 저장소의 GitHub Pages에서, 백엔드와 데이터베이스는 사용자 본인의 AWS 계정에서 실행됩니다.
