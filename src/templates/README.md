# 로컬 더미 템플릿 페이지

`/template/{id}` 로 열리는, 이 앱 안에서 직접 그린 템플릿 페이지 셋입니다.

| ID     | 이름               |
| ------ | ------------------ |
| maru   | MARU 한옥 스테이   |
| kiln   | KILN 도예 공방     |
| noctua | NOCTUA 독립 영화관 |

**목록에 뜨는 템플릿은 여기 없습니다.** 그쪽은 서버 카탈로그(`GET /templates`)에서
오고, 데모는 GH Pages 에 실제로 떠 있는 페이지입니다(`demoUrl`).

예전에는 이 폴더가 홈 목록에 쓸 더미 12종과 썸네일도 함께 들고 있었습니다. 그 id 들이
서버가 아는 `templateType` 이 아니라, **골라도 프로젝트에 얹히지 않았습니다** —
`/project/new` 라우트가 진짜 카탈로그 id 를 "모르는 값" 으로 보고 첫 더미로 바꿔치기하던
버그도 그 목록 때문이었습니다. 목록을 카탈로그로 옮기면서 걷어냈습니다.

남은 이 셋은 목록과 무관하게 주소로만 열리는 페이지라 그대로 둡니다.
